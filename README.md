## Overview

Mini Games is a collection of simple and interactive browser games created for fun while improving front-end development skills. Each game is built as an individual project with clean UI, responsive layouts, and engaging gameplay.

This repository is perfect for showcasing creativity, logic-building, DOM manipulation, and JavaScript fundamentals.

---

## Projects Included

| Project | Description | Live Demo |
|---|---|---|
| **Tech Personality Quiz** | Discover your tech personality based on your answers | https://tech-personality-quiz.vercel.app/ |
| **Hangman Game** | Guess the hidden word before you run out of chances | https://hangman-game-psi-rosy.vercel.app/ |
| **Tic-Tac-Toe** | Classic two-player strategy game | https://tic-tac-toe-nine-alpha-43.vercel.app/ |
